# VTU AI Study Assistant

An AI-powered study platform for VTU engineering students, built with the MERN stack and Google Gemini.

## Features

- AI Chat tutor with formatted answers
- Upload notes (PDF) and get AI summaries
- Important questions generator (module-wise)
- Quiz generator with timer, review and progress tracking
- Previous year paper analyzer (up to 10 PDFs, OCR for scanned papers)
- Saved analyses per student, with delete
- Four colour themes (Indigo, Dark, Emerald, Ocean)

## Tech stack

React + Vite, Node.js, Express, MongoDB (Mongoose), JWT authentication, Google Gemini API.

## Setup

1. Clone the repository.
2. Backend:
   - `cd backend`
   - copy `.env.example` to `.env` and fill in your values
   - `npm install`
   - `npm run dev`
3. Frontend:
   - `cd frontend`
   - `npm install`
   - `npm run dev`
4. Open http://localhost:5173
